# 記事用の図の作成手順

## 0. 前提

- 図は draw.io で作り、mxGraph XML を直接手書きする（GUI は使わない）。
- ソースは記事と同じ場所の `images/<name>.drawio` に置く。リポジトリに構成の決まり（CI のチェックなど）があればそちらに従う。
- PNG への書き出し: `drawio -x -f png -s 2 -b 10 -o <name>.png <name>.drawio`
- 本文からの参照: `![代替テキスト](images/<name>.png)`
- 同じ記事やリポジトリに既存の図があれば、最初にその `.drawio` を読み、配色・フォント・レイアウトの慣習を揃える。以下の規約は、既存の図がないときの既定値。

## 1. 何を描くかを決める

- 1枚に込める主張は1つにする（例: 「A の中に B が入れ子になっている」「複数の経路が1か所に集まる」）。
- 主張に合わせて種類を選ぶ。

| 見せたいこと | 種類 |
|---|---|
| 処理が実行される順番、条件による分岐 | フロー |
| 何が何を持っているか（包含関係） | 構造（入れ子） |
| 主体 × 役割の組み合わせ | 対応表 |

- 要素名はコード上の識別子をそのまま使う（型名、フィールド名、関数名）。
- 実在しない呼び出しや入れ子を描かない。描く前にソースで確かめる。
- 本文で説明していることは図に書かない。付箋（shape=note）による補足も禁止。

## 2. 種類ごとの描き方

### フロー

- 進む向き（上→下 または 左→右）は1枚の中で統一する。
- 外から入ってくる入力（リクエスト、メッセージなど）は shape=message のアイコンにラベルを添え、起点にする。
- 分岐
  - 条件で分かれるとき: ひし形（rhombus）に条件を書き、出ていく線に「一致」「それ以外」などのラベルを付ける。
  - 振り分け先を並べるだけのとき: ひし形を使わず、二股の矢印にする。
- 主体（背景帯）をまたぐ線は強調色にし、線の上に何を渡しているか（例: 「= X の Handler」）を書く。
- 補助的な経路や「該当なしのとき」の経路は dashed=1 にする。そのフローで通らない部品は、破線・灰色の文字で残す。

### 構造（入れ子）

- 外側の箱から内側の箱へ入れ子にする。
- 各箱のラベルは左上に「フィールド名　*型名」の形で書く（verticalAlign=top、align=left）。
- 同じ階層の箱は大きさを揃え、内側ほど余白を詰める。
- 構造の中にフローを描くとき、主役は外枠（構造）で、矢印（フロー）は補助にとどめる。

### 対応表

- 行の見出しは主体の色、列の見出しは役割の色にする。ほかの図での色の意味と一致させる。
- セルは白地にして、枠線を列の見出しの色に揃える。
- 該当がないセルは空けず、灰色の文字で「〜なし」と書く。

## 3. スタイルの既定値

- 主体（サーバ、プロセス、モジュールなど）の背景帯
  - rounded=0、strokeColor=none、ラベルは右上寄せ
  - 淡い色を主体ごとに1色ずつ割り当て（例: #FFE6CC / #B0E3E6 / #E1D5E7）、記事内で同じ主体には同じ色を使い続ける。
- 部品ボックス: rounded=1、arcSize=12、fillColor=#FFFFFF、strokeColor=#333333
- 役割ごとの色

| 役割 | fill | stroke |
|---|---|---|
| 入口 | #DAE8FC | #6C8EBF |
| 主要な部品1 | #D5E8D4 | #82B366 |
| 主要な部品2 | #FFF2CC | #D6B656 |
| 末端・フォールバック | #EEEEEE | #999999 |
| 強調・注意の線 | — | #C0504D |

- フォント: コード識別子は Menlo 12px、日本語の説明は Helvetica 11px、帯の見出しは 13px 太字
- XML ではまとまりごとに `<!-- 入口 -->` のようなコメントを入れる。

## 4. 本文への配置

- 置く順番は「導入の1〜2文 → 図 → 詳しい説明・コード」。
  - 見出しの直後にいきなり図を置かない。「〜は次のとおりです」のように、何の図かを先に書く。
  - 節の最後に図を回さない。
- コードが多い節ほど図を増やす。

## 5. 確認

PNG を書き出したら Read で画像を開き、次の点を目で確かめる。

- 文字のはみ出し、矢印の交差、箱や帯の重なり
- 配色と用語が、記事内のほかの図や本文と揃っているか
- 本文と同じ説明が図に入っていないか
